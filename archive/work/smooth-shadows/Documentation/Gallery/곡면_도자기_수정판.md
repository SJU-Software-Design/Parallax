# 곡면 도자기 수정판

> 이전 곡면 모델 버전의 기록입니다. 계단형 그림자는 이후 [매끄러운 도자기 그림자 수정판](매끄러운_도자기_그림자.md)에서 개선되었습니다.

2026-10-03. 각진 청화 각병을 직접 제작한 곡면 청화 모란병으로 교체했습니다. 겹창 조각과 기존 9개 사물은 유지합니다.

## 실행

상위 폴더의 추가판_실행.cmd → Parallax_Unity_v0.8.2_Ceramics/Parallax.exe.
이전 게임이 켜져 있으면 종료한 다음 실행하세요. 도자기 위치는 1구역 입구 오른쪽 (3.25, 1.05, 5.35)입니다.

왼쪽 클릭 잡기/놓기, 시선 거리로 확대/축소, Q/E 및 Z/X 회전, 오른쪽 클릭 취소, R 구역 초기화. 총 11개 조작 사물이며 새 클리어 조건은 없습니다. 새 병은 뚜껑이나 발판이 없는 열린 입구 형태입니다.

## 직접 제작한 모델

GalleryCeramicMesh.cs에서 베지어 곡선 단면을 128방향으로 회전시켜 실제 메시를 제작했습니다. 배 모양 몸통, 좁은 목, 벌어진 입구, 두께 있는 테두리, 안쪽 벽과 바닥을 포함합니다. 높이 약 2.1 게임 단위, 몸체와 링 합계 29,025 정점 / 56,832 삼각형이며 평활 노멀과 UV가 있습니다. 외부 완성 모델을 가져오지 않았습니다.

porcelain-peony-wrap.png는 새로 생성한 2172×724 청화 모란 문양입니다. 몸통을 감싸는 UV, Unity Standard 유약 재질, 보조 조명으로 표현했습니다. OBJ, MTL, PNG를 같은 폴더에 두면 다른 3D 프로그램에서 열 수 있습니다. OBJ는 게임용 충돌체와 조명 설정은 포함하지 않습니다.

GalleryPuzzleExhibits.cs가 배치하며 GalleryGame.Awake와 GalleryBuild.Prepare에서 추가합니다. 에디터의 Parallax → 미술관 씬 준비는 메시와 재질을 저장하도록 연결했습니다. 이 메뉴는 씬 전체를 재생성하므로 수동 씬 수정은 먼저 별도 보관하세요.

## 빌드와 검증 범위

Unity Editor가 설치되어 있지 않아 기존 Unity 6000.3.24f1 Windows 플레이어의 별도 복사본에 런타임 C#을 컴파일했습니다. Unity Editor 전체 재빌드와 에디터 메뉴 실행은 미검증입니다. 원본 Gallery 플레이어는 보존했습니다. 기존 플레이어는 제거된 PNG API 대신 동일 PNG의 손실 없는 RGBA 사본을 읽고, 일반 Unity 빌드는 PNG를 읽습니다.

새 전시물: 조작 자세 1,154개, 충돌체/그림자 광선 1,994개, 잡기·크기 변경·회전·취소·낙하·초기화 통과.
기존 원근 조작 회귀 검사 통과, CPU/GPU 그림자 샘플 65,600개에서 불일치 0개.
전체 4구역 수동 완주 검증은 아닙니다.

## 알려진 한계: 그림자 품질 미완성

위 테스트 통과는 곡면 그림자의 품질 통과가 아닙니다. 도자기 충돌체와 퍼즐 그림자는 50개 숨겨진 박스이며, 전체 그림자 차폐체 126/128개를 사용합니다. 바닥 그림자에 계단형 경계가 남습니다. GPU 그림자와 곡면 메시 직접 투영의 IoU는 약 84.5~84.6%입니다. 도자기 Standard 렌더러에는 기존 커스텀 퍼즐 그림자가 수광되지 않습니다.

그림자 검토 요청에 대해서는 원인을 재현하고 근거를 남겼으며, 그림자 계산 방식 자체는 변경하지 않았습니다. 자세한 결과는 도자기_그림자_검토.md에 있습니다.
