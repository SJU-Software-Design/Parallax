# 매끄러운 도자기 그림자 수정판

2026-10-03. 도자기의 계단형 박스 그림자를 실제 곡면 단면 기반 그림자로 교체했습니다.

## 실행

기존 게임 창을 닫고 상위 폴더의 추가판_실행.cmd를 실행하세요.
대상은 Parallax_Unity_v0.8.2_SmoothShadows/Parallax.exe입니다.
1구역 오른쪽 도자기를 햇빛이 드는 바닥으로 옮기면 둥근 그림자를 확인할 수 있습니다.
기존 원본 Gallery 및 이전 Ceramics 폴더는 변경하지 않았습니다.

## 변경 내용

- 도자기 메시와 같은 199점 베지어 샘플 단면으로 빛의 교차를 계산합니다. 각 단면 구간은 원형의 잘린 원뿔 표면으로 해석됩니다.
- 도자기의 50개 박스는 잡기·배치·물리 충돌용으로 유지하되, 보이는 그림자와 안전한 그늘 판정에서는 제외했습니다.
- GPU의 GalleryCurvedShadow.cginc와 CPU의 GalleryCurvedCaster.cs가 같은 단면, 바운드, 교차식을 사용합니다.
- 바닥뿐 아니라 기존 GallerySurface 셰이더를 사용하는 표면에 반영합니다. 천창 마스크와 다른 사물의 기존 그림자는 유지합니다.
- 회전·크기 변경·낙하·취소·구역 초기화 때 변환 행렬을 갱신합니다.
- 박스 그림자 차폐체는 76개입니다. 기존 128행렬 버퍼 중 단면 데이터 25개 슬롯과 변환/메타데이터 1개 슬롯을 추가로 사용합니다.
- 씬에서 발견하는 곡면 차폐체 필드는 NonSerialized로 두어 기존 Windows 씬의 저장 형식을 유지합니다.

## 실제 GPU 검증

각 자세마다 512×512 샘플에서 GPU 그림자를 메시 삼각형 직접 투영과 비교했습니다.
원래 박스 버전은 84.52%에서 99% 품질 기준에 실패하는 것을 먼저 확인했습니다.

| 자세 | 곡면 메시와 그림자 IoU | CPU/GPU 불일치 픽셀 |
| --- | ---: | ---: |
| 직립 | 99.9664% | 0 |
| 기울임 | 99.9712% | 1 |
| 최대 2.8배 | 99.9850% | 0 |
| 뒤집기 | 99.9664% | 0 |
| 최소 0.45배, 가로로 눕힘 | 99.9768% | 0 |

총 1,310,720개 샘플 중 CPU/GPU 차이는 윤곽 경계의 1픽셀입니다. 검사 허용치는 자세당 최대 2픽셀이고, 메시 IoU는 99% 이상이어야 합니다. 원형 해석과 128방향 폴리곤 메시의 미세한 차이 및 부동소수점 경계 차이는 남습니다.

새 사물 조작 검사: 1,154개 자세와 충돌 외형 광선 1,994개, 잡기·확대/축소·회전·취소·놓기·낙하·초기화 통과.
기존 원근 조작 회귀 검사: 그림자 샘플 65,600개에서 CPU/GPU 불일치 0개, 낙하 및 크기 보존 검사 통과.
실제 RTX 5060 / Unity 6000.3.24f1 / Direct3D 11 플레이어에서 검증했습니다.

## 빌드 및 재현

Unity Editor는 설치되어 있지 않습니다. 런타임 C#을 별도 Windows 플레이어에 컴파일하고, Windows SDK fxc로 GallerySurface의 DX11 픽셀 셰이더를 컴파일했습니다. 수정 에셋에서 셰이더 객체 30만 변경했으며, 다른 객체·텍스처·모델·버텍스 셰이더·리소스 바인딩은 보존 검증했습니다.

일반 Unity 빌드의 원본은 GallerySurface.shader와 GalleryCurvedShadow.cginc입니다. Unity Editor 전체 재빌드 및 에디터 메뉴 실행은 이번 환경에서 검증하지 않았습니다.

Tools/Build/Patch-CurvedShader.py는 기존 Windows 실행본을 재현하기 위한 보조 도구입니다.
Python, UnityPy 1.25.0, Windows SDK fxc가 필요합니다. --source와 --target에는 서로 다른 sharedassets0.assets 파일을 지정해야 합니다. --resources는 두 셰이더 소스가 있는 폴더, --output은 중간 결과 폴더입니다. SDK 경로가 다르면 --fxc로 지정하세요. 도구는 기존 셰이더의 플랫폼과 상수 버퍼·텍스처 바인딩이 정확히 맞는 경우만 처리합니다. 일반 Unity Editor 빌드에서는 이 보조 도구가 필요 없습니다.

## 범위와 남은 한계

곡면 그림자의 윤곽을 수정한 것이며, 태양의 반그림자를 흐리게 만드는 소프트 섀도우 효과는 추가하지 않았습니다.
도자기 자체의 Standard 유약 재질에 다른 사물의 커스텀 그림자를 수광하는 기능은 이전과 동일하게 미지원입니다.
현재 갤러리에는 곡면 도자기 하나가 있으며, 여러 곡면 차폐체를 추가하려면 데이터 버퍼 구성을 확장해야 합니다.
전체 4구역 수동 완주 및 다른 그래픽 API/기기의 실행은 검증하지 않았습니다.
