# 도자기 그림자 검토

2026-10-03. 결론: 조작과 그림자 판정은 동작하지만, 현재 그림자는 매끄러운 곡선 품질에 미달합니다.

## 원인

GalleryCeramicMesh.Visual은 실제 곡면 메시를 렌더링하지만 shadowCastingMode=Off입니다. GalleryCeramicMesh.Colliders는 10개 높이 구간 × 5개 깊이 띠, 총 50개 박스로 충돌/그림자용 외형을 근사합니다. GallerySurface.shader는 이 박스들의 역변환 행렬로 광선 교차를 계산합니다. 따라서 모델 메시의 곡선이 그대로 투영되지 않습니다.

기존 GPU/CPU 일치 테스트는 같은 박스 표현을 양쪽에서 비교하므로 통과하더라도 메시 윤곽과의 일치를 보장하지 않습니다. 이번에는 메시를 직접 삼각형 투영한 참조 마스크와 실제 GPU 셰이더를 별도로 비교했습니다.

IoU는 두 영역의 교집합/합집합이며 높을수록 일치합니다. 현재 그림자는 몸통·목 가장자리에서 계단처럼 꺾이고 실제 메시보다 넓습니다. 이는 단순 화면 안티앨리어싱 문제가 아니라 박스 외형 자체의 차이입니다.

06-actual-shadow-in-sunlight.png는 실제 미술관의 햇빛 아래로 도자기를 옮긴 진단 장면입니다. 일반 배치 위치는 원래대로 복구됩니다. shadow-*-difference.png에서 주황색은 불필요하게 추가된 그림자, 자홍색은 빠진 그림자, 짙은 색은 메시 그림자입니다.

## 추가 한계와 권장 후속 수정

도자기의 Standard 재질은 커스텀 퍼즐 그림자 수광을 사용하지 않습니다. 광택용 조명은 있으나 몸체가 다른 사물의 그늘에 들어가는 표현까지 연결된 상태는 아닙니다.

곡선에 맞추려면 렌더링되는 그림자와 플레이어 안전 판정 양쪽이 같은 곡면 기반 표현을 사용하도록 변경해야 합니다. 보이는 그림자만 부드럽게 바꾸면 안전 판정이 어긋날 수 있습니다. 현재 전체 박스 차폐체는 126/128개라서 박스 수를 조금 추가하는 방식에는 여유가 거의 없습니다.

이번 요청에서는 그림자 구현을 변경하지 않고 문제를 검토·재현했습니다. 별도의 곡면 그림자 수정 작업이 필요합니다.
