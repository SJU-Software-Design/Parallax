# 이전 실험 — Parallax v0.6 — 원근의 열쇠

> 추가 실내 실험: `Assets/Parallax/Legacy/Scenes/Indoor.unity`와 `실내스테이지실행.cmd`에서 v0.7 실내 조명 통로를 확인할 수 있습니다. 조작과 빌드 방법은 [실내 맵 안내](Indoor-README.md)에 있습니다. 아래 내용은 기존 열쇠 버전 안내입니다.

강아지 퍼즐이 없는 기본 Courtyard에 **크기를 맞추는 열쇠와 잠긴 문**을 추가한 버전입니다. 기존 햇빛 노출·그늘 연결·복귀를 유지하고, 출구의 2.7m 발판을 제거해 **점프 없이 걸어서 탈출**합니다.

## 실행

프로젝트 최상단의 **열쇠퍼즐실행.cmd** 또는 **배포자료/Parallax_Unity_v0.6_Key/Parallax.exe**를 더블클릭하고 **열쇠를 찾아 시작하기**를 누릅니다. Windows 64비트 실행 파일이며 Unity 설치는 필요 없습니다. 다른 PC에 전달할 때는 Parallax_Data, UnityPlayer.dll 등을 포함한 배포 폴더 전체를 복사하세요.

강아지 퍼즐은 후보로 보류했습니다. 기존 **그림자퍼즐실행.cmd**는 이전 v0.5를 계속 실행하며, 그 버전의 실행 파일은 덮어쓰지 않았습니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| WASD / 마우스 | 이동 / 시점 |
| 왼쪽 클릭 | 열쇠 또는 기존 사물 집기 / 내려놓기 |
| F | 열쇠 원근 크기 조절 ↔ 크기를 고정하여 운반 |
| E 또는 자물쇠를 보고 클릭 | 들고 있는 열쇠를 자물쇠에 꽂기 |
| Space | 점프 가능, 출구 탈출에는 필요 없음 |
| R | 열쇠·문·사물·진행 전체 초기화 |
| Esc | 일시정지, 메뉴 및 마우스 잠금 해제 |

열쇠는 시작 그늘의 왼쪽 KEY 표시에 있습니다. 클릭으로 들면 크기가 유지됩니다. **F를 누르고 먼 바닥을 보면 커지고, 가까운 바닥을 보면 작아집니다. 다시 F를 누르면 그 크기를 고정해 들고 이동**합니다. 조절 중 클릭하면 현재 유효 위치의 바닥에 놓습니다.

원근 조절 중에는 플레이어 위치를 고정합니다. 휠로 숫자를 바꾸는 방식이 아니라, 원래 사물과 같은 크기/거리 비율로 실제 모델이 변합니다. 벽 밖, 사물 안이나 사물 너머에는 배치할 수 없으며 실패하면 마지막 유효 크기와 위치를 유지합니다. 너무 큰 키로 가까운 공간이 막히면 더 먼 빈 바닥에서 조절 모드를 시작합니다.

화면 왼쪽에 자물쇠 대비 크기와 허용 구간을 표시합니다. **목표 100%, 허용 92~108%**입니다. 너무 작거나 크면 이유를 표시하고 열쇠를 그대로 돌려줍니다. 맞는 크기를 자동으로 만들어 주지는 않습니다.

## 한 가지 진행 방법

1. 열쇠를 클릭해 집어 보고 F로 크기를 맞춥니다. 그늘 안에서 조절하면 안전합니다. 크기는 도착 구역에서 나중에 맞춰도 됩니다.
2. 열쇠를 잠시 내려놓고 기둥을 크게 만들어 시작 그늘과 가운데 쉼터를 잇습니다. 열쇠를 다시 집고 그늘을 따라 건넙니다.
3. 쉼터에서 열쇠를 내려놓고 차광판을 크게 만들어 두 번째 그늘 길을 잇습니다. 열쇠를 다시 집습니다.
4. 차광판의 오른쪽을 돌아 도착 그늘로 갑니다. 연결된 그늘 길로 도착하면 자동 저장됩니다.
5. 출구 자물쇠 앞에서 크기가 맞는 열쇠를 들고 E를 누릅니다. 가까이에서 자물쇠를 조준해야 합니다.
6. **삽입 → 약 90도 회전 → 딸깍 소리 → 고리 해제와 문 열림**이 약 2.2초 동안 이어집니다. 연출 중 시점이 자물쇠 옆으로 잠시 이동해 동작을 보여주고 돌아옵니다. 열쇠의 선택한 크기는 그대로 유지됩니다.
7. 열린 출구로 걸어 나가면 완료됩니다. 사물을 발판으로 만들 필요가 없습니다.

열쇠를 운반할 때도 햇빛 노출이 적용됩니다. 게이지가 가득 차면 마지막 저장 그늘로 돌아가고, 들고 있던 열쇠와 크기는 유지됩니다. 크기 조절 중 복귀하면 운반 모드로 돌아옵니다. 바닥에 내려놓은 키는 그 위치에 남습니다. 사물을 조작할 때는 열쇠를 먼저 내려놓아야 합니다.

잠금 해제 중 이동·중복 입력은 막으며 Esc로 연출과 소리를 멈출 수 있습니다. R로 초기화하면 문도 다시 잠기고 지연된 효과가 남지 않습니다. 열쇠 없이 문 앞에 도착하거나 잠금만 먼저 풀어도 그늘 도착 조건이 없으면 완료되지 않습니다.

## Unity 소스와 검증

Unity 6000.3.24f1 / C# / Built-in / DirectX 11. **Assets/Parallax/Legacy/Scenes/Courtyard.unity**에서 Play하면 열쇠 버전이 기본 실행됩니다. 방은 런타임에 생성합니다.

    .\Tools\Build\Build-Windows.ps1
    .\Tools\Validation\Test-KeyPuzzle.ps1
    .\Tools\Validation\Test-Player.ps1

- `KeyPuzzle.cs`: 열쇠 크기·운반·배치·조준·자물쇠 상태와 진행
- `KeyPuzzleVisuals.cs`: 열쇠·자물쇠 메시, 삽입·회전·문 열림, 합성 딸깍 소리
- `KeyPuzzleHud.cs`: 열쇠 버전 안내·크기 표시·진행 메뉴
- `ShadeRules.cs`: 원본 규칙과 바닥 높이 출구 옵션
- `KeyPuzzleSmoke.cs`: 정상 입력 경로를 사용한 운반·크기·잠금·무점프 탈출 자동 검증
- `Assets/Parallax/Legacy/Editor/KeyPuzzleTests.cs`: 크기 허용 경계, 잠금 순서, 중복 실행 및 평지 출구 규칙

`Validation/KeyPuzzle/key-smoke-results.json`과 PNG에 새 버전의 자동 진행 결과를 보관합니다. 실제 3D 카메라를 숨긴 창에서 렌더한 이미지이므로 IMGUI 메뉴/HUD는 포함하지 않습니다. 자동 검증은 실제 게임의 조준·상호작용·이동 API를 구동하며, OS 마우스·키보드 조작을 통한 수동 플레이는 별도입니다. 딸깍 소리는 오디오 데이터와 재생 호출을 검증했으며 스피커 청취 검증은 하지 않았습니다.

기존 모드 회귀 검사는 `Tools/Validation/Test-Player.ps1`(원본), `Tools/Validation/Test-Integrated.ps1`(보류한 강아지 통합), `Tools/Validation/Test-ShadowPuzzle.ps1`(과거 독립 갤러리)입니다. 이전 규칙은 명시적인 실행 인수에서만 사용합니다. 새 기본 플레이에는 강아지 도형이나 액자가 없습니다.

`Validation/BeforeKeyPuzzle/`에 v0.5 변경 전 소스를 보관했습니다. 이전 실행 파일도 보존했습니다. Mac 빌드·패키징 경로는 v0.6으로 맞췄지만 이번 제공물은 Windows이며 Mac 실행 검증은 하지 않았습니다.
