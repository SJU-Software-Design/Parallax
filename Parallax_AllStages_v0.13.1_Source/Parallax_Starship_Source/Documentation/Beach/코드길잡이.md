# 마지막 해변 v0.11.0

Unity 6000.3.24f1의 Built-in 렌더러를 사용합니다. 시작 씬은 `Assets/Parallax/Beach/Scenes/Beach.unity`입니다.

| 위치 | 역할 |
| --- | --- |
| Scripts/BeachGame.cs | 이동·점프·원근 조작·취소·복귀·클리어 |
| Scripts/BeachWorld.cs | 해변 네 구역, 소품·수로·모래성·체크포인트 배치 |
| Scripts/BeachProp.cs | 물리 상태와 크기, 구체 충돌, 초기 위치 복원 |
| Scripts/BeachLighting.cs | 표시 메시를 이용한 햇빛·반사광 차광 판정 |
| Scripts/BeachMirror.cs | 이동·확대 가능한 거울과 반사 카메라·반사광 |
| Scripts/BeachWater.cs | 물 접촉, 부력, 방향성 물살, 도착 감지 |
| Scripts/BeachLightGate.cs | 두 센서 충전·수문 개방 |
| Scripts/BeachWaterGateLink.cs | 운반 완료 후 보행로 개방 |
| Scripts/BeachHud.cs | 시작·일시정지·클리어 메뉴와 상태·선택형 힌트 |
| Editor/BeachBuild.cs | 에셋 변환 결과를 Unity 메시로 가져오기, 씬 생성·빌드 |
| Validation/BeachValidation.cs | 실제 실행 파일의 자동 검증 |
| Resources/BeachWater.shader | 흐름 방향을 표시하는 물 표면 |

이 표의 상대 경로는 `Assets/Parallax/Beach`를 기준으로 합니다. 미술관·도서관은 각각 별도 폴더와 씬에 유지합니다.

```powershell
.\Tools\Build\Build-Beach.ps1
.\Tools\Validation\Test-Beach.ps1
python Tools/Share/Export-Beach-Source.py --output ../03_공유용_소스
```

빌드 도구는 씬을 다시 생성합니다. 배치를 지속적으로 바꾸려면 `BeachWorld.cs`를 수정해야 합니다. Unity에서 씬만 수동 수정한 뒤 재생성하면 해당 배치가 덮어써질 수 있습니다.

에셋 원본 GLB는 작업 폴더의 `에셋/Beach_Surf_and_Paddle_Kit_3DAssets`, 변환 JSON은 `Assets/ThirdParty/3DAssetsBeach`, Unity 메시·재질은 `Beach/Generated`에 있습니다. 런타임용 메시를 이미 포함하므로 다른 팀원이 게임을 열 때 다운로드나 GLB 플러그인 설치는 필요 없습니다.

그림자 판정은 비충돌 레이어 30의 원본 메시 복사본을 사용합니다. 사물의 물리 충돌체는 조작 안정성을 위한 복합 상자 또는 구체입니다. 파라솔의 빈 공간을 전체 상자 그림자로 처리하지 않습니다. 실제 렌더링의 그림자 경계와 판정 간 오차는 플레이 검증에서 확인할 항목입니다.

검증은 준비한 기믹 배치를 사용합니다. 전체 풀이를 스스로 찾아 완주한 테스트, 장시간 성능 측정, IMGUI 메뉴의 화면 캡처 검증은 포함하지 않습니다. 자세한 범위는 검증결과.txt를 참고하세요.
