# 설치 규칙 v0.12.0

`Assets/Parallax/Shared/Scripts/PlacementSupport.cs`가 운반·지지·안착 상태를 관리합니다. 원래 렌더 재질을 보관하고 미설치 상태에서는 반투명 재질을 사용하며 플레이어와의 충돌만 제외합니다. 벽·바닥·다른 사물과의 배치 충돌 검사는 기존 컨트롤러가 유지합니다. 원래 걸린 그림의 고정 상태와 부력 지지를 별도로 다룹니다.

`PlacementLesson.cs`는 설치 규칙 4단계 안내입니다. 조작을 자동 수행하거나 진행을 강제로 막지 않습니다. `PlacementValidation.cs`는 실제 입력 경로와 별도 물리 배치를 구분한 회귀 검사입니다.

미술관·도서관의 `Lighting`과 `Surface.shader`는 같은 설치 상태를 사용해 실제 그늘과 파란 예상 그늘을 구분합니다. 해변의 `BeachLighting.cs`는 비활성 사물의 메시 판정을 제외하고 `BeachPlacementPreview.cs`는 별도 깊이 텍스처로 예상 그늘을 그립니다. 실제 빛과 노출 판정은 이 미리보기 텍스처를 사용하지 않습니다.

`BeachMirror.cs`는 설치된 거울만 실제 반사광을 켭니다. `BeachWater.cs`는 수면 지지와 실제 물살 운반을 처리합니다. 재잡기는 운반 거리 누적을 지우며 취소는 직전 물리·부력·설치 상태를 복원합니다.

빌드: `Tools/Build/Build-Placement.ps1` (전체), `-Stage Beach|Gallery|Library` (개별).
설치 규칙 검사: `Tools/Validation/Test-Placement.ps1 -Stage Beach|Gallery|Library`.
퍼즐 회귀 검사: `Test-Beach.ps1`, `Test-Gallery-Mirror.ps1`, `Test-Library.ps1`.
