# 이전 실험 — Parallax v0.7 — 빛 사이를 건너다

실내에서도 **어두운 쉼터 → 반드시 건너야 하는 밝은 통로 → 다음 쉼터** 구조로 원근과 그림자 이동이 성립하는지 확인하는 작은 Unity 예제입니다.

## 실행

- 프로젝트 최상단 `실내스테이지실행.cmd`를 더블클릭합니다.
- 또는 `배포자료/Parallax_Unity_v0.7_Indoor/Parallax.exe`를 실행합니다.
- 시작 화면에서 **실내 통로 시작하기**를 누릅니다.
- Windows 64비트용입니다. 플레이할 때 Unity 설치나 로그인이 필요하지 않습니다.
- 공유하려면 `배포자료/Parallax_Indoor_v0.7_Windows.zip` 전체를 전달하고, 받은 사람이 압축을 풀어 `Parallax.exe`를 실행합니다. EXE와 Data 폴더, DLL은 함께 있어야 합니다.

기존 열쇠 v0.6과 강아지 후보 v0.5의 실행 파일은 각자의 폴더에서 계속 실행할 수 있습니다. 이 실내 예제는 그늘 이동을 살펴보는 별도 씬입니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| WASD / 마우스 | 이동 / 시점 |
| 왼쪽 클릭 | 사물 잡기 / 현재 크기와 위치로 놓기 |
| 잡은 상태에서 시선 조절 | 가까이 놓으면 작게, 멀리 놓으면 크게 |
| 오른쪽 클릭 | 잡기 전 위치와 크기로 취소 |
| H | 전체 배치도와 배치 위치 힌트 |
| R | 전체 처음부터 |
| Esc | 일시정지 / 계속하기 |

원근 조절 중에는 플레이어 위치가 고정됩니다. 사물의 크기는 잡았을 때의 크기/거리 비율에 따라 정해집니다. 벽이나 다른 사물에 겹치면 마지막 가능한 위치를 유지합니다. 클릭해서 놓은 뒤 이동합니다.

## 플레이 흐름

1. 시작 쉼터에서 01 기둥을 조준하고 클릭합니다. 고개를 조금 들어 사물을 멀리 놓으면 커집니다.
2. 첫 번째 밝은 통로를 지나 **중간 쉼터 쪽에** 기둥을 배치합니다. 뒤쪽 천장 조명이 기둥의 그림자를 시작 지점 쪽으로 길게 만듭니다.
3. 그림자가 시작 쉼터와 중간 쉼터를 연결하면 클릭해서 놓고, 그늘을 따라 걸어갑니다. 중간 쉼터는 자동 저장됩니다.
4. 기둥 옆으로 돌아서 **중간 쉼터 앞쪽의 바닥 02 표시**까지 이동합니다. 이 위치에서 02 차광판을 잡으면 원근으로 충분히 크게 만들 수 있습니다.
5. 차광판을 도착 쉼터 쪽으로 크게 놓아 두 번째 그림자 길을 만듭니다. H로 배치 위치 힌트를 볼 수 있습니다.
6. 도착 쉼터에서 차광판 옆으로 돌아 정면 출구로 걸어갑니다. 점프는 사용하지 않습니다.

노란 조명 바닥은 위험하고 진한 그늘과 어두운 쉼터는 안전합니다. 밝은 곳에서 노출 게이지가 가득 차면 마지막 저장 쉼터로 돌아옵니다. 사물 배치는 유지됩니다.

## 설계와 구현 범위

- 폭 9.2m, 길이 36m인 실내 통로에 고정 조명 두 개와 쉼터 세 곳을 배치했습니다.
- 조명이 비추는 두 구간은 벽에서 벽까지 이어집니다. 바닥 구간을 옆으로 돌아서 통과할 수 없습니다.
- 각 조명은 사각 차광 후드로 통로의 정해진 구간을 비추는 설정입니다. 원근으로 바뀐 사물의 8개 꼭짓점을 실제 광원 위치에서 바닥으로 투영하고, 조명 구간에 맞춰 잘라 그림자를 만듭니다.
- 바닥의 빛과 그림자는 읽기 쉽게 표현한 기하학적 렌더입니다. 화면의 그림자 메시와 노출 판정이 같은 다각형을 사용합니다. 자연광 전체를 계산하는 물리 기반 조명 시뮬레이션은 아닙니다.
- 플레이어 발 주변의 작은 여유 폭을 포함해 안전 여부를 판정합니다. 연결 표시와 H 배치도는 보조 안내입니다.
- 조명 이동, 열쇠, 강아지 퍼즐은 이 예제에 포함하지 않았습니다. 우선 실내 그늘 경로를 직접 확인하는 버전입니다.

## Unity 편집과 검증

Unity 6000.3.24f1에서 `Assets/Parallax/Legacy/Scenes/Indoor.unity`를 열어 Play합니다. 기존 열쇠 씬은 `Assets/Parallax/Legacy/Scenes/Courtyard.unity`입니다.

```powershell
.\Tools\Build\Build-Indoor.ps1
.\Tools\Validation\Test-Indoor.ps1
```

- `IndoorRules.cs`: 점 광원 그림자, 안전 구역, 원근 배치, 연결 경로
- `IndoorGame.cs`: 이동·잡기·노출·체크포인트·탈출
- `IndoorVisuals.cs`, `IndoorHud.cs`: 실내 공간과 한국어 안내
- `IndoorSmoke.cs`, `Assets/Parallax/Legacy/Editor/IndoorTests.cs`: 플레이 흐름과 규칙 검증

결과는 `Validation/Indoor/`에 저장합니다. 자동 진행은 일반 조준·잡기·놓기·이동 함수를 호출하며, 물체 크기나 플레이어 위치를 직접 정답으로 대입하지 않습니다. 그림자 판정은 별도의 3D 광선/상자 교차 방식과 3,536개 바닥 지점에서 비교합니다. 자동 진행 PNG는 Unity 카메라의 실제 3D 렌더이며 HUD를 포함하지 않습니다. OS 마우스로 전체 플레이를 수동 수행한 검증과는 구분됩니다.
