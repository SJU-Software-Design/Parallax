# 햇빛 튜토리얼 3스테이지 플레이 초안

## 목적과 합의한 구성

2스테이지의 높은 문을 걸어 나가면 같은 높이의 ㄱ자 채광실로 이어진다. 시점은 유지한다. 세 햇빛 구간 사이에 넓은 고정 쉼터를 두고 주사위를 하나씩 추가 제공한다. 첫 구간은 그늘 만들기, 두 번째는 그늘 연결, 마지막은 꺾인 길에 맞는 배치를 익힌다. 모든 주사위를 쓰도록 강제하지 않는다.

실패하면 마지막 쉼터로 돌아오고 놓은 물체는 유지한다. 태양은 고정한다. 기존 크기 조절, 착지 피드백과 1·2스테이지를 재사용한다. ESC에는 3스테이지 바로가기를 추가한다.

## 이번 실행

사용자가 요청한 플레이 가능한 초안이다. 기존 단일 그림자 연결안, 넓은 중정안, 두 물체 재사용안 중 ㄱ자 채광실과 구간별 물체 추가를 선택했다. 최종 미술과 그림자 길이의 정밀 튜닝은 플레이 피드백 후 진행한다. 별도 브랜치에서 구현하며 자동 PR/병합은 하지 않는다.

1. `TutorialGame.Sunlight.cs`에 방, 쉼터, 세 주사위, 고정 햇빛과 노출·체크포인트 처리를 추가한다.
2. `TutorialGame.cs`, `TutorialGame.Climb.cs`에 자연스러운 출구 연결, 물체 목록, 초기화, ESC 바로가기를 연결한다.
3. `TutorialSunlightDraftChecks.cs`에서 실제 장면의 햇빛/차광, 연결 가능한 예시 동선, 복귀 시 배치 유지와 스테이지 전환을 확인한 뒤 macOS 초안을 빌드한다.
4. 새 초안을 3스테이지에서 실행한다. 새 화면을 확인하고 사용자에게 실행 상태와 초안의 한계를 알린다.

초안은 테스트 우선 개발을 생략하고 실제 Unity 장면 검사와 한 번의 빌드로 검증한다. 태양 판정은 주사위·지붕의 실제 물리 형상을 사용한다. 주사위의 작은 모서리 라운딩은 상자 충돌체에 포함되므로 가장자리에 미세한 여유가 있다.
