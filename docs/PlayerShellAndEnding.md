# Parallax 0.39 · 시작화면과 일식 엔딩

이 통합본은 시작화면 → 튜토리얼 → 미술관 → 해변 → 일식 퍼즐 → 엔딩 크레딧 → 시작화면을 연결합니다. 기존 팀원 UI 시안 PR의 글래스 HUD는 포함하지 않습니다.

## 빌드와 실행

Unity **6000.3.24f1**, Windows x64 Build Support(Mono), Built-in Render Pipeline이 필요합니다. 저장소 루트에서 다음을 실행합니다.

~~~powershell
.\scripts\run-complete.ps1 -BuildOnly
.\scripts\run-complete.ps1 -Run
.\scripts\run-complete.ps1 -Rebuild -BuildOnly -UnityEditor 'X:\Unity\6000.3.24f1\Editor\Unity.exe' -WorkspaceRoot 'X:\ParallaxBuilds'
~~~

빌드 스크립트는 원본 projects/all-stages 대신 별도 생성 프로젝트에서 작업하고, 성공한 빌드만 실행 대상으로 승격합니다. 시작 씬은 MainMenu이며 Tutorial, Gallery, Beach, Eclipse까지 총 5개 씬이 활성화됩니다. Library는 이번 진행에 포함하지 않습니다.

## 플레이어 메뉴와 저장

- 학교 로고와 프로젝트 소개가 사라진 뒤 Parallax 제목, 스위치 소리, 점등과 배경 순서로 시작합니다.
- 새 게임, 이어하기, 환경설정, 나가기를 제공하고 엔딩 완료 후 수동 크레딧 열람이 추가됩니다.
- Esc는 게임 재개, 설정, 현재 구간 다시 시작, 저장하고 나가기를 표시합니다. 일반 플레이어에게 관리자 이동 메뉴는 보이지 않습니다.
- 진행은 각 맵의 마지막 체크포인트 단위로 저장합니다. 이어하기는 해당 체크포인트와 완료 기믹을 복원합니다.
- 새 게임과 이어하기에 페이드, 로딩 바, Tip이 나오며 이어하기의 6개 Tip 중 검 개발 비화는 해당 기믹을 만난 후에만 선택됩니다.
- 공통 설정에서 음량, 화면, 접근성 옵션과 조작키를 바꿀 수 있습니다.

## 테스트용 관리자 메뉴

시작화면의 **Parallax 로고 위에 마우스를 둔 상태에서 왼쪽 클릭 2회 → 오른쪽 클릭 3회 → 백틱 키**를 입력하면 테스트용 관리자 모드가 켜집니다. 관리자 Esc → 맵 이동에서는 먼저 맵을 고르고, 그 맵의 구간을 선택합니다.

| 맵 | 선택할 수 있는 구간 |
| --- | --- |
| 튜토리얼 | 0-1 크기 조작, 0-2 주사위 발판, 0-3 햇빛과 그늘 |
| 미술관 | 1-1 시작 전시실, 1-2 니케, 1-3 병·디케, 1-4 초상, 1-5 성당의 손 |
| 해변 | 2-1 태양광, 2-2 정원, 2-3 그림자 배, 2-4 수중 천막 인양 |
| 일식 | 크레딧 전, 크레딧 후 |

관리자 테스트 저장과 정상 진행 저장은 분리됩니다. 관리자 엔딩 완료는 일반 플레이의 영구 크레딧 해금을 기록하지 않습니다. 구간 바로 실행이 필요한 경우 빌드한 exe에 **-admin-start-section Gallery 4**처럼 명시합니다. 인덱스는 0부터 시작합니다. 이 옵션이 없으면 정상 시작화면으로 시작합니다.

## 맵 마무리와 엔딩

튜토리얼의 햇빛 노출 게이지, 잡을 수 없는 사물의 피드백, 미술관 벽·전시물 끼임과 마지막 벽 외형을 보완했습니다. 미술관 손 포털은 가속하며 아래로 떨어지는 연출을 유지하고, 주변 구조물이 보이지 않는 공간과 하강 바람을 사용합니다. 실제 해변 로드 중에만 완전히 암전합니다.

해변에서 출항한 뒤 일식 맵으로 이어집니다. 달의 보이는 크기를 유지하며 잡고 옮기고, 실제 태양 가림률이 충분하면 일식이 진행됩니다. 크기보다 가림률을 기준으로 사용하며 지면 접촉·플레이어 겹침·조작 시야를 처리합니다. 출발 안전지대는 실제 그림자가 있고 태양을 볼 수 있도록 낮은 가림벽을 사용합니다.

일식 후 바닥을 크레딧 화면으로 사용하며 카메라가 올라갔다가 플레이어 시점으로 돌아옵니다. 제작진과 마지막 **THANK YOU FOR PLAYING**은 건너뛸 수 없습니다. 외부 자료 구간에서는 Space로 빠르게 넘기거나 Esc로 마지막 감사 인사까지 이동할 수 있습니다. 자료마다 사용 위치, 제작자와 출처를 기재합니다.

EXIT로 걸어 들어가면 전진과 바람, 암전, **감사합니다**, 음악의 마무리와 페이드, 검은 화면 대기 후 시작화면의 제목·점등 연출로 복귀합니다. 엔딩 뒤 크레딧 메뉴는 음악 없이 마우스 휠로 읽습니다.

## 검증 범위

기존 0.39 실행본은 Editor 125개, 격리한 Windows 플레이어 2,235개 검사를 통과했습니다. PR의 이식 빌드와 추가 검사 결과는 [검증 기록](validation/PlayerShellEnding-20261121.json)에 별도로 기록합니다. 기존 결과와 새 빌드 결과를 같은 DLL의 검사로 합산하지 않습니다.

검사는 실제 PhysX, 체크포인트 복원, 메뉴 계층, 구간 로드, 카메라 상태, 글자 배치와 오디오 데이터를 확인합니다. 스크린샷 외형 승인, 주관적인 청음 또는 사람이 입력만으로 전 구간을 완주한 결과를 의미하지 않습니다. 기존 사용자 앱과 저장 파일은 보존합니다.

검증 실행기도 제공합니다. 아래 경로는 각자 빌드한 플레이어 폴더와 아직 존재하지 않는 새 결과 폴더로 바꾸세요. ExpectedAssemblySha256에는 해당 실행본의 Parallax_Data/Managed/Assembly-CSharp.dll SHA-256을 전달합니다.

~~~powershell
.\scripts\validate-player-shell.ps1 -PlayerDirectory 'X:\ParallaxBuilds\Latest\Tutorial' -ResultDirectory 'X:\ParallaxValidation\run-01' -ExpectedAssemblySha256 '<64자리 DLL SHA-256>'
~~~

7개 격리 프로세스에서 엔딩·완료 재로드, 메뉴·체크포인트와 재로드, 손 포털 낙하, 관리자 14구간과 마지막 미술관 구간 기동을 순서대로 검사합니다. 원본 PPT 대신 승인 역할 transcript를 사용하는 공개 fixture의 범위는 projects/all-stages/Documentation/Validation/FixtureContracts.md를 확인하세요.
## 출처

새 자료의 고지는 Assets/Parallax/Shared/ThirdParty/PlayerShellSources, Assets/Parallax/Eclipse/ThirdParty, Assets/Parallax/Gallery/ThirdParty/PassageAudio에 있습니다. 기존 미술관·해변의 고지는 유지합니다. 게임의 크레딧에는 승인한 역할과 134개 사용 자료를 표시합니다. 원작자·라이선스·사용 위치는 재배포한 고지와 함께 확인할 수 있습니다.

기존 SourceManifest.json과 과거 릴리스 문서는 당시 버전의 기록이며 이 버전 전체의 파일 목록이나 새 빌드 검증 결과가 아닙니다.
