# 로컬 확인 방법

Unity 6000.3.24f1에서 `projects/all-stages` 프로젝트를 엽니다.
`Assets/Parallax/Beach/Scenes/Beach.unity`를 열고 Play로 확인합니다.
`Parallax > 마지막 해변 씬 준비`를 실행한 뒤에도 같은 변경이 적용됩니다.

이 PR은 main을 기준으로 해당 에셋 변경만 담았습니다. 다른 미술 에셋 PR,
바닥 모래 PR 또는 물 PR을 먼저 머지하지 않아도 됩니다. 공통 partial hook은
네 에셋 PR에 동일하게 들어 있으며, 구현하지 않은 hook은 컴파일러가 제거합니다.
목재와 모래성 PR의 공통 셰이더·미리보기 include·텍스처 helper도 동일한 파일입니다.

비포·애프터 PNG는 이 PR만 적용한 실제 Beach 씬 Play Mode에서 동일한
카메라·시야·조명으로 촬영한 1920×1080 원본입니다. HUD는 카메라 출력에
포함되지 않습니다. 별도 색 보정·합성·생성 이미지는 사용하지 않았습니다.

검증은 각각의 단독 브랜치 및 네 변경을 합친 별도 체크아웃에서 진행했습니다.
셰이더, 물체 11개·물 구역 4개·쉼터 4곳과 씬 재생성을 확인했습니다.
전체 퍼즐 완주, 별도 실행 파일 빌드와 GPU 성능 측정은 수행하지 않았습니다.
