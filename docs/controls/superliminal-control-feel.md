# Superliminal 분석 기반 조작감 적용 기록

2026-10-31. 사용자가 제공한 Windows 설치본 정적 분석을 동작 기준으로 적용했다. 원본 게임의 입력 지연이나 DPI를 직접 측정한 결과는 아니다.

## 적용 범위

- 전체 스테이지 소스의 Gallery, Library, Beach, Starship.
- `Parallax_Gallery_Source` 단독판. 공통 상호작용·이동 코드를 같은 내용으로 포함한다.
- 기존 그림자·거울·체크포인트·물 위 발판·공중 이동·엔딩 조건은 유지한다.
- 원본의 포털·복제·멀티플레이·플레이어 크기 변환은 현재 게임에 없는 별도 기능이므로 추가하지 않았다.

## 핵심 동작

| 항목 | 적용값 / 동작 |
| --- | --- |
| 이동 | 4 u/s, 키보드 축 상승·복귀 3/s, 방향 반전 시 0부터 시작 |
| 입력 곡선 | 정규화 방향 × min(1, 길이)²; 대각선 최고속도 제한 |
| 지상 / 공중 가속 | 56.6 / 15 u/s² |
| 점프 | 중력 20, 초기 속도 6, 기본 높이 0.9, 추가 홀드 높이 약 0.5 |
| 점프 경계 | 선입력 50ms, 도약부터 0.75초 쿨다운, 코요테 타임 없음, 최대 낙하속도 20 |
| 충돌 | 발 기준 높이 1.6, 반지름 0.3, 중심 높이 0.8, 계단 0.2, skin 0.05, 경사 한도 60° |
| 눈 높이 | 발 기준 1.55; 원본의 중심 기준 좌표를 기존 맵의 발 기준 좌표로 변환 |
| 턱 오르기 | 점프 후 전진·하강·도달 가능한 윗면·머리 공간 조건, 약 0.3초; 충돌을 유지한 위→앞 경로 |
| 마우스 | smoothing / dt 배율 없이 즉시 시점에 반영; 아래 70° / 위 90° |
| 시야각 | 기본 70°, 메뉴에서 70–90° 저장; near clip 0.05 |
| 잡기 | 중앙 레이 + 가려짐을 확인하는 마우스 0.05 / 패드 0.1u 선택 보조 |
| 초기 정렬 | 최초 카메라 공간 방향에서 중앙까지 0.8초 ease-out |
| 원근 배치 | 물체 중심거리와 크기의 비례를 유지; 전체 복합 실루엣·화면 밖 부분·두께를 반영 |
| 환경 여유 | 투영 거리에 0.99; 무환경 투영 fallback 400u; 기존 맵 경계·크기 제한 적용 |
| 몸 겹침 | 투영 중심을 유지하고 크기를 10회 이분 탐색으로 축소; 최소 크기에도 불가하면 놓기 거부 |
| 회전 | 카메라 yaw를 따라가며 기본 수평 유지; 기존 Q/E·Z/X 수동 회전·기울기 유지 |
| 놓기 | 현재 카메라로 재계산·검증한 뒤 중력과 동적 물리 복원; 이동속도 던지기 없음 |
| 놓은 물체 | 기존 세제곱 질량·안전 상한 유지, ContinuousDynamic 2초 후 원래 모드 복원 |
| 피드백 | 조준·보유·회전·막힘 커서, 잡기·놓기·충돌음, 0.43초 발소리·점프·착지음 |

Rewired와 Unity legacy mouse delta의 단위가 같다는 근거가 없어, 감도 2에서 기존 Unity 배율 0.023rad를 유지하고 조절 가능하게 했다. 패드 radial deadzone 0.15는 이 프로젝트의 선택값이며, 원본에서 확인된 공통값이 아니다. 패드 시점은 1초 방향 램프, 수평/수직 최대 300/240°/s, 조준 근처 수평 0.65배, 보유 중 수직 1.5배다. 원본의 프레임 단위 보간·회전 시간처리 문제는 복제하지 않았다.

## 조작

| 입력 | 동작 |
| --- | --- |
| WASD / 왼쪽 스틱 | 이동; 물체를 든 상태에서도 가능 |
| 마우스 / 오른쪽 스틱 | 시점 |
| Space | 점프; 짧게/길게 누르기 구분 |
| 왼쪽 클릭 | 잡기 / 놓기 토글 |
| 오른쪽 버튼 누른 채 마우스 | 카메라를 멈추고 물체 회전 |
| Backspace | 잡기 전 위치·크기·물리·부유 상태로 취소 |
| Q/E, Z/X, C | 기존 회전·기울기·바로 세우기 |
| R / Shift+R | 구역 / 전체 초기화 |
| Escape | 일시정지; 입력만 비우고 공중 궤적·쿨다운·턱 오르기 상태 보존 |

감도·시야각·축 반전은 메뉴에서 저장한다. 고정 거울의 기존 조작 종료 동작은 유지한다. 기본 90 FPS 제한은 일반 플레이에서 해제하고 VSync를 사용한다.

## 검증

- 전체 스테이지: 기존 상호작용 65, 새 중심거리·선택 보조·정렬·몸 겹침·놓기 24, 투영 해석값·화면 밖·fallback 3, 이동·통합·벽·일시정지 27, 입력 8, 놓기 물리 36, 이동음 8. 총 171개 통과.
- Gallery 단독판: 기존 잡기 7 + 투영 3 + 이동 27 + 입력 8 + 놓기 물리 8 + 이동음 8. 총 61개 통과.
- 기존 Rule / Indoor / Courtyard / Key / ShadowPuzzle 규칙 검증 통과.
- Python 빌드 명령 회귀 검사 8개 통과.
- 30/60/120 FPS의 입력 램프·점프와 대각선 벽 미끄러짐 검사. 벽 접촉 시 접선 속도가 매 프레임 감쇠하던 회귀를 수정했다.
- 독립 코드 검토 후 지적된 일시정지 궤적 초기화, 벽 접선 감속, 이동 소리 누락을 해결했다. 공통 소스의 미러 일치 여부를 확인했다.
- macOS에서 Gallery 화면·이동/점프 입력·일시정지·옵션 UI 확인. 우주선의 Windows 글꼴 의존으로 비어 있던 HUD는 macOS 글꼴 선택으로 수정했다.

프레임 시간·입력부터 디스플레이까지의 지연·물리 패드·원본과 나란히 비교한 주관적 조작감·각 맵 처음부터 끝까지 무도움 클리어는 측정하지 않았다. 패드는 legacy Xbox 계열 첫 장치 매핑이므로 실제 장치 확인이 필요하다.

## 실행 및 재검증

실행 빌드:

- `Builds/macOS/Parallax.app`: Gallery 단독판.
- `Builds/ControlFeel/Starship.app`: 우주선 체험판.

Unity 6000.3.24f1 배치 실행의 `-executeMethod`:

- 두 프로젝트: `ShadeLink.Editor.ControlFeelValidation.RunAll`.
- Gallery macOS 빌드: `ShadeLink.Editor.GalleryPlatformBuild.BuildMacOS`.
- 전체 스테이지 소스의 우주선 macOS 빌드: `ShadeLink.Editor.ControlFeelBuild.BuildMacStarship`.

검증 로그와 보고서는 `Builds/ControlFeel/Validation/`에 보관한다. 빌드는 기존 방식대로 씬을 코드에서 다시 생성하므로 수동 씬 편집본은 별도로 보관한다.
