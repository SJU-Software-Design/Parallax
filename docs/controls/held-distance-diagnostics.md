# 보유 물체 거리 제한 진단 — Gallery v4

2026-11-01. `play-gallery-v4.cmd` 또는 최신 `play-gallery.cmd`로 실행한다. 기존에 켜둔 v2/v3 창에는 새 표시가 없으므로 v4를 실행한다. 이전 v3는 `play-gallery-v3.cmd`로 실행할 수 있다.

## A/D로 확인하기

1. 물체를 잡는다. 화면 위 중앙에 진단 패널이 기본으로 나타난다.
2. 시점을 유지하고 A/D로 이동한다. 제한 원인과 충돌체 이름이 매 프레임 갱신되는지 본다.
3. `실제 표면 충돌`이면 다음 줄의 이름과 `#인스턴스 ID`, 아래 계층 경로가 현재 거리를 결정한 충돌체다. 예를 들어 바닥, 입구 벽, 복도 옆벽, 전시물이다.
4. 노란 `+`는 해당 실루엣 광선의 실제 환경 명중 지점 또는 공간 경계의 제한 꼭짓점이다. 중앙 조준점과 다른 곳에 있어도 정상이다. 화면 바깥이면 가장자리에 `화면 밖`으로 표시한다.
5. F3으로 패널과 표시를 숨기거나 다시 켠다. 물체를 놓으면 자동으로 사라진다.

캡처를 전달할 때 제한 원인, 이름, 경로와 아래 수치가 모두 나오도록 하면 원인을 좁힐 수 있다.

## 패널의 의미

| 표시 | 의미 |
|---|---|
| 실제 표면 충돌 | 전체 물체 실루엣의 광선 중 가장 가까운 허용 거리를 만든 실제 충돌체 |
| 공간 경계 | X/Y/Z 최소·최대 중 물체 꼭짓점이 닿는 제한 평면 |
| 물체 최대 크기 | 물체별 MaxScale을 잡을 때 저장한 크기/거리 비율로 환산한 거리 상한 |
| 조작 의도 거리 상한 | 호출자가 별도로 전달한 거리 상한. 일반 Gallery 경로는 제한 없음 |
| 물체 전체 부피 겹침 | 유한 광선이 놓친 모서리를 마지막 부피 검사로 보완한 경우. 정확한 접촉점은 없으므로 충돌체 외곽 범위만 표시할 수 있다 |
| 카메라가 충돌체 내부 | 광선 시작점이 실제 고체 안에 있어 원거리 투영을 거부한 경우 |
| 최소 거리/경계 조건 충돌 | 최소 허용 깊이와 상한 조건이 충돌해 유효한 배치 해가 없는 경우. 찾은 원인 충돌체·경계 지점은 보존한다 |
| 표면 없음 · 기본 거리 | 환경 표면을 찾지 못한 경우의 기본 400m 후보. 경계나 크기 상한이 더 작으면 그 원인을 표시한다 |

`계산`은 이번 solver가 구한 잡기점 거리다. `적용`은 현재 화면에 있는 물체의 잡기점과 카메라 사이 실제 거리다. 물체 중심까지의 거리와는 다를 수 있다. 실패 후 안전 자세를 유지하면 두 값이 달라질 수 있으며 패널 마지막 줄에 그 상태를 표시한다.

`표면 / 경계 / 크기 상한 / 의도 상한`은 각각의 독립 후보 거리다. 표면 후보에는 기존 접촉 여유가 반영된다. 마지막 부피 보정이나 유효성 실패가 있으면 단순한 후보 최솟값만으로 최종 화면 자세를 설명할 수 없으므로 상태 줄도 함께 본다. `플레이어 겹침 배율`은 마지막 적용 시도에서 플레이어 회피를 위해 계산한 추가 크기 배율이며, 거리 상한과는 별개다.

노란 외곽 사각형은 월드 AABB를 화면에 투영한 범위이며 정확한 충돌 형상/접촉점이 아니다. 카메라 근평면을 가로지르는 범위는 잘못된 사각형을 피하기 위해 그리지 않는다.

## 구현과 검증 범위

- 두 프로젝트의 공통 `PerspectivePlacement`가 실제 선택한 collider/hit/boundary와 후보 깊이를 결과에 기록한다. 별도 조준 광선이나 추가 물리 쿼리를 만들지 않는다.
- `ObjectInteraction`이 직접 계산 자세 적용 성공 여부를 기록하고, 두 Gallery의 `HeldPlacementDiagnosticsOverlay`가 읽어서 표시한다. Gallery가 아닌 스테이지에는 이번 화면을 붙이지 않았다.
- 표면/경계/크기/의도 제한, 옆 장애물 제거 후 원인 갱신, 카메라 내부 충돌, 최소 거리와 벽 충돌 시 원인 보존을 자동 검사한다. 기존 기하 기대 깊이도 확인한다.
- v3의 작은 물체 놓기와 내부 구역 경계 제거를 유지한다. 이번 변경은 진단 정보 표시이며, 기존 거리·크기 계산 수식과 물리 쿼리 흐름을 유지한다.
- 로그: `artifacts/validation/editor-build/diagnostics-gallery.log`, `diagnostics-all-stages.log`, `gallery-v4-build.log`. 실제 실행 결과와 화면은 `artifacts/validation/gallery-v4/`에 저장한다.
