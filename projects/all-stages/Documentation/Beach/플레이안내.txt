Parallax — 마지막 해변 v0.12.1

운반과 설치 규칙 (v0.12.0)
WASD 이동·Space 점프는 사물을 잡고 있을 때도 가능합니다.
잡은 사물은 반투명해지고 파란 빗금의 예상 그늘만 표시합니다. 예상 그늘은 보호 효과가 없습니다.
놓은 사물이 바닥이나 다른 설치된 사물에 받쳐 안정된 상태를 0.35초 유지하면 실제 그늘과 발판이 활성화됩니다.
공중에서 놓거나 아직 흔들리는 상태에서는 보호되지 않습니다. 다시 잡으면 즉시 효과와 안정화 시간이 해제됩니다.
벽에 처음 걸려 있던 미술관 그림은 설치된 상태로 시작합니다. 잡아서 떼면 이후에는 물리적으로 내려놓아야 합니다.
물에 뜨는 해변 사물은 안정적으로 부력을 받으면 설치를 인정하고 물살에 따라 계속 이동합니다.
해변 거울도 내려놓고 안착해야 실제 반사광과 센서 충전이 켜집니다. 운반 중 파란 광선은 방향 미리보기입니다.
물살 운반 도중 사물을 다시 잡으면 운반 누적 거리가 초기화됩니다. 취소하면 잡기 직전 상태를 복원합니다.
T: 설치 연습 안내 표시/숨김. 잡고 이동 → 크기를 바꿔 놓기 → 안착 확인 → 설치한 그늘로 이동 순서로 안내합니다.
전체 기본 조작·복구·거울 과정을 모두 포함하는 전용 튜토리얼은 후속 작업입니다.
오른쪽 클릭은 잡기 취소, R은 현재 구역 초기화, Shift+R은 전체 초기화입니다.
시작 지점 또는 다음 쉼터의 고정 그늘에서 배치하고, 설치 완료 표시를 확인한 뒤 이동하세요.

2026-10-07 / Windows 64비트 / Unity 6000.3.24f1

실행
작업 폴더의 윈도우/바다스테이지실행.cmd를 실행합니다.
공유 ZIP은 압축을 모두 푼 뒤 Parallax.exe 또는 게임실행.cmd를 실행합니다.
게임 실행에 Unity 설치나 에셋 사이트 가입은 필요 없습니다.
시작 화면에서 '해변 입장'을 누릅니다. Esc로 일시정지할 수 있습니다.

조작
WASD 이동 / 마우스 시점 / Space 점프
왼쪽 클릭 잡기·놓기 / 오른쪽 클릭 잡기 취소
Q·E 회전 / Z·X 기울기 / C 바로 세우기
H 현재 구역 힌트 / R 현재 구역 초기화 / Shift+R 전체 초기화
Esc 일시정지·계속 / 메뉴의 종료 버튼

사물을 잡은 채로 이동하거나 점프할 수 있습니다.
잡은 사물 뒤의 가까운 표면을 보면 작아지고 먼 표면을 보면 커집니다.
크기 조절에 마우스 휠을 사용하지 않습니다.
배치가 막히면 마지막 유효 위치에서 멈춥니다. 방향을 바꾸거나 취소할 수 있습니다.
취소는 잡기 직전의 위치·각도·크기를 되돌립니다.
복원 위치에 플레이어가 서 있으면 옆으로 이동한 뒤 취소하세요.
놓은 물체에는 중력·충돌이 적용됩니다. 파라솔과 거울은 정한 각도를 유지합니다.

전체 규칙
햇빛과 거울 반사광에 노출되면 화면의 노출 게이지가 오릅니다.
그늘로 들어가면 회복합니다. 물에 닿으면 그늘 안이어도 즉시 복귀합니다.
판자 위를 건널 때는 판자 윗면, 성벽에서는 그 높이에 그늘이 필요합니다.
일반 실패 시 놓은 사물의 배치는 유지합니다. 들고 있던 사물은 잡기 전 상태로 돌아갑니다.
R은 현재 구역의 사물과 관련 문을 되돌립니다. Shift+R은 전체 상태를 되돌립니다.
사물은 원래 제공된 구역 안에서 조작합니다. 진행용 물체를 다른 구역으로 빼내지 않습니다.
세 스테이지는 현재 별도 실행 파일입니다. 하나의 연속 플레이로 연결하는 작업은 남아 있습니다.

01 작은 거울, 넓어지는 빛
작은 거울을 잡아 먼 모래 위에 크게 배치합니다.
Q/E와 Z/X로 두 센서를 함께 비추도록 반사 방향을 조절합니다.
거울의 위치가 반사광의 출발점, 각도가 반사 방향, 크기가 빛의 폭에 영향을 줍니다.
태양 자체를 옮기는 방식은 아닙니다.
해변의 센서 문은 충분히 충전되면 열린 상태를 유지합니다.
파라솔이나 돗자리를 키우고 배치해 햇빛·반사광을 가린 뒤 열린 문을 통과합니다.

02 판자 위에 그늘을 놓다
수로는 일반 점프만으로 건너기 어렵습니다.
짧은 판자를 확대해 양쪽 둑에 걸쳐 실제 통로를 만듭니다.
별도의 파라솔을 확대해 판자 윗면을 가립니다.
판자에 올라갈 때 점프가 필요할 수 있습니다. 반대편 쉼터까지 그늘과 노출 시간을 계산합니다.

03 물살에게 사물을 맡기다
흰 화살표 방향으로 물살이 흐릅니다.
비치볼이나 판자를 입구 쪽 물 위에 놓으면 부력과 물리 계산으로 반대편에 이동합니다.
충분한 거리를 떠내려온 물체가 도착 구역에 들어가면 수문과 오른쪽 보행로가 열립니다.
물살 운반에 성공하면 파라솔·차광막으로 보행로에 그늘을 만들고 이동합니다.
반대편에는 처음부터 이동 가능한 소품을 두지 않았습니다. 운반한 사물을 회수해 다시 쓸 수 있습니다.
물체를 잘못 보냈다면 R로 해당 구역을 초기화합니다.

04 모래성 꼭대기의 출구
오른쪽 성벽을 따라 등반 턱이 이어집니다.
첫 턱은 일반 점프보다 높으므로 의자 등 사물을 발판으로 사용합니다.
그다음은 높이와 간격을 보며 점프합니다. 판자를 발판과 연결 통로로 재사용할 수 있습니다.
파라솔은 넓이뿐 아니라 높이도 키워 높은 성벽에 그늘을 만들어야 합니다.
오른쪽 중간 성벽의 고정 파라솔 아래에 안전하게 착지하면 중간 위치가 저장됩니다.
정상 출구는 모래 바닥보다 약 6.7m 높습니다.
두 수문을 연 뒤 그늘 속에서 정상 출구에 착지하면 클리어합니다.

난이도와 교수 피드백
마지막 단계에 기존 원근·회전·운반·그늘 규칙과 물살·점프를 조합했습니다.
힌트는 H로 선택하고, 우클릭 취소·구역 초기화·중간 복귀로 실수를 복구할 수 있습니다.
기존 요구사항 문서의 단계별 튜토리얼은 별도 목표입니다. 이 실행 파일은 마지막 스테이지 프로토타입입니다.
전체 풀이 시간과 최종 난이도 수치는 팀의 실제 플레이 후 조정해야 합니다.

v0.12.1 물속 사물 회수
물에 잠긴 사물을 조준해 왼쪽 클릭으로 잡은 뒤 시선을 위로 올려 꺼냅니다.
확대한 비치볼도 물속에서 원근 크기 변경·이동·놓기가 가능합니다.
수로의 실제 바닥은 모래 높이보다 2m 아래입니다. 뜨지 않는 파라솔·거울도 무한히 가라앉지 않습니다.
판자·비치볼·의자·돗자리의 부력과 물살 이동은 유지합니다. 물은 플레이어에게 계속 위험합니다.
사물을 들고 있는 동안에는 안전한 그림자와 발판 효과가 없습니다.
