튜토리얼 사운드 적용·해제 안내 — 2026-11-13

이 작업은 PR #41의 튜토리얼 음원만 사용합니다. 미술관 PR #40은 병합하지 않았습니다.

공통 처리의 의미
- PlayerMovementAudio: 플레이어의 발걸음·점프·착지 시점을 계산합니다.
- PropReleasePhysics: 물체의 물리 상태와 잡기·놓기·접촉 시점을 처리합니다.
- TutorialAudio: 튜토리얼에서 사용할 음원과 재생 방식을 선택합니다.
  여러 맵이 처리 경로를 공유해도 각 맵·물체의 음원은 다르게 정할 수 있습니다.

공통 효과음 끄기
- 실행 인자: --tutorial-common-sfx-off
- 실행 중 코드: TutorialAudio.Instance.CommonEffectsEnabled = false;
- 다시 켜기: TutorialAudio.Instance.CommonEffectsEnabled = true;
- 적용 범위: 이번 튜토리얼의 발소리·플레이어 착지·잡기·놓기·물체 충돌음.
- 끄는 순간 재생 중이거나 일시정지한 해당 효과음을 정지합니다.
- 이후 효과음을 처리 완료로 반환하여 이전 합성음이 대신 재생되지 않게 합니다.
- 이동·잡기·놓기·충돌 물리와 BGM·UI·문·퍼즐 완료음은 유지합니다.
- 이 설정은 튜토리얼 전용이며 다른 맵의 음량·효과음에는 적용하지 않습니다.

후속 교체·제거
- 지금은 공통 효과음 전체의 켜기/끄기를 제공합니다. 사물별 음원 편집 UI는 없습니다.
- 음원 교체는 TutorialAudio.Files의 경로와 해당 TutorialAudio/Selected 파일에서 합니다.
- 사물별 분기가 필요하면 TutorialAudio.Play에 이미 전달되는 owner를 기준으로
  음원 선택을 확장할 수 있습니다. 이번 수정에서 사물별 분기는 추가하지 않았습니다.
- 음향을 완전히 제거할 때는 TutorialAudio 연결과 공통 스크립트의 음원 라우팅을
  별도로 제거합니다. 물리·이동 처리는 해당 스크립트에 보존합니다.
- PR #41 원본과 이번 낙하 오류 수정·효과음 스위치를 각각 분리해 추적합니다.

주사위 낙하 오류 수정
중앙 풀에서 재생하는 경우 주사위 자체에는 AudioSource가 없습니다.
자동 낙하 연출은 기존 AudioSource가 존재할 때만 거리 값을 설정합니다.
