# Museum artwork plaque typography

The bronze artwork catalogue plaques use the unmodified **Nanum Myeongjo** font family, copyright 2010 NHN Corporation, designed by Fontrix.

- Title: `NanumMyeongjo-Bold.ttf`.
- Artist, date and medium: `NanumMyeongjo-Regular.ttf`.
- Original binaries: [Google Fonts / Nanum Myeongjo](https://github.com/google/fonts/tree/main/ofl/nanummyeongjo).
- License: [SIL Open Font License 1.1](https://github.com/google/fonts/blob/main/ofl/nanummyeongjo/OFL.txt).
- The original copyright and complete license are retained in `Assets/Parallax/Gallery/Resources/MuseumTypography/OFL.txt` and shipped as `MuseumTypography-OFL.txt` next to full museum builds.
- Source URLs and SHA-256 values are retained in the adjacent `sources.json`.

The font files are included in Unity rather than selected from the host OS so the plaque typography remains the same on macOS and Windows. Existing gameplay and instruction labels retain their original typeface.
