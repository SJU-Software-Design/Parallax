## 처음 읽는 순서

1. `GalleryGame.Update`에서 입력 처리와 조작 흐름을 확인합니다.
2. `Interact`에서 잡는 기준점과 초기 거리·크기를 확인합니다.
3. `ResolvePlacementDepth`, `PerspectivePose`, `UpdateHeldPose`에서 시선 거리와 원근 배율, 이동 중 충돌 처리를 확인합니다.
4. `GalleryProp.BeginHold`와 `Release`에서 조작과 물리가 전환되는 지점을 확인합니다.
5. `GalleryLighting`과 `GallerySurface.shader`에서 같은 차광 정보를 판정과 화면에 사용하는 방식을 확인합니다.

## 거울과 들고 이동

`GalleryGame.Tick`은 들고 있는 상태에서도 CharacterController 이동과 중력을 계산하고, 이동한 카메라에서 `UpdateHeldPose`를 다시 실행합니다. 취소 시 잡기 전 위치가 플레이어와 겹치면 취소를 보류하고 안내합니다. 구역 초기화와 복귀는 강제 취소 후 플레이어를 안전 지점으로 옮깁니다.

`InterpolatePreview`는 이동 전 사물의 실제 크기에서 새 목표 크기로 보간합니다. 이동한 카메라로 이전 거리와 크기를 다시 계산하지 않아, 바닥에 닿은 사물도 시선을 따라 연속적으로 운반할 수 있습니다. 이동·회전·성장 중간의 충돌 검사는 유지합니다.

`GalleryLighting.IsSunlit`은 직사광 또는 반사광 중 하나라도 도달하면 참입니다. 반사광은 유한한 거울 면에 대한 역방향 교점, 천창에서 거울까지의 차폐, 거울에서 표면까지의 차폐를 확인합니다. CPU와 `GallerySurface.shader`가 같은 상수·사물 행렬·거울 정보를 사용합니다. 거울은 한 번의 반사만 지원합니다.

`GalleryWorld.MirrorRoom`에 두 번째 구역의 차양, 거울, 유리 통로, 센서 문, 차광판을 구성합니다. 차광판은 기존 9개 사물 뒤에 추가하여 기존 사물 인덱스를 유지합니다.

새 검증은 `Tools/Validation/Test-Gallery-Mirror.ps1`입니다. 검증 결과의 범위 설명을 확인하세요. 독립 광학 배치 검사와 실제 조작 검사를 구분합니다.

## 공통 코드와 이전 실험

`Shared/Scripts/ShadeRules.cs`에는 Player 등의 공통 자료형과 기존 규칙이, `IndoorRules.cs`에는 미술관 시선 계산에서도 사용하는 보조 함수가 있습니다. 기존 기능을 바꾸지 않기 위해 네임스페이스와 클래스명은 유지했습니다.

`Legacy/Scripts`는 `Courtyard`, `KeyPuzzle`, `ShadowPuzzle`, `Indoor`로 나누었습니다. 이전 씬은 `Legacy/Scenes`, 이전 빌드·규칙 검증 코드는 `Legacy/Editor`에 있습니다. 이전 버전의 F 조작 설명은 현재 미술관에 적용되지 않습니다.

`Gallery/Generated`와 `ThirdParty/ALLrounder18`의 메시·텍스처, `.meta` 파일은 저장된 씬의 참조 대상입니다. C# 파일만 복사하면 같은 미술관을 실행할 수 없으므로 전체 소스 ZIP을 공유하세요.
