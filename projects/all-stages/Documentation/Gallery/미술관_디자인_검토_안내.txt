PARALLAX 미술관 디자인 검토 v0.18.0

실행
작업 폴더의 미술관_디자인_미리보기.cmd를 실행합니다.
원본 Unity 프로젝트: SW기초설계github/projects/all-stages

이번 검토본
구상안의 네 전시실을 새로 구성했습니다. 기존 맵의 높은 발판 코스는 사용하지 않습니다.
실제 명화, 니케 실물 석고상 3D 스캔, 외부 흉상과 식물 모델을 배치했습니다.
돌·회벽·목재 PBR 재질, 곡면 몰딩, 격자 천창과 아치형 창을 적용했습니다.
이동과 전시물 조작은 해변맵과 동일한 최신 공통 시스템을 사용합니다.

조작
WASD 이동 / 마우스 시점 / Space 점프
복제작품·원근 전시물: 왼쪽 클릭 잡기와 놓기
들고 시선을 움직이면 표면 거리로 크기가 바뀝니다.
오른쪽 버튼+마우스 상하좌우 회전 / 잡을 때 자동 바로 세우기
Backspace 잡기 취소 / R 현재 전시실 초기화 / Esc 메뉴

검토 범위
현재는 공간과 그래픽을 둘러보는 자유 관람 버전입니다.
햇빛 노출로 되돌아가는 진행 규칙은 이 검토본에서 잠시 껐습니다.
시점 설치물은 디자인을 볼 수 있도록 완성 배치에서 시작합니다.
오르쿠스의 사용 가능한 고품질 원본은 아직 확보하지 못했습니다.
네 번째 전시실의 최종 조각과 새 배치에 맞춘 퍼즐·도서관 연결은 남아 있습니다.
따라서 v0.17의 퍼즐 검증 결과를 새 디자인의 완성 검증으로 간주하지 않습니다.
