# 도서관 코드 길잡이

도서관은 `Assets/Parallax/Library/Scenes/Library.unity`에서 시작합니다. 미술관은 기존 `Gallery.unity` 씬과 `ShadeLink.Gallery` 코드를 유지합니다. 도서관 코드는 `ShadeLink.Library` 네임스페이스로 분리했습니다.

## 읽는 순서

1. `LibraryGame.Update`에서 입력과 조작 흐름을 확인합니다.
2. `Interact`에서 잡은 지점, 기준 거리, 기준 배율을 확인합니다.
3. `ResolvePlacementDepth`, `PerspectivePose`, `UpdateHeldPose`에서 시선에 따른 거리와 크기, 이동 경로의 충돌 검사를 확인합니다.
4. `LibraryProp.BeginHold`, `Release`, `Restore`에서 잡기·낙하·초기화 상태가 전환되는 부분을 확인합니다.
5. `LibraryWorld.Build`와 `LibraryLighting`, `LibrarySurface.shader`에서 맵 구조와 그림자 판정을 확인합니다.

## 파일별 역할

표의 경로는 `Assets/Parallax/Library/` 기준입니다. `LibraryGeometry.cs`는 파일명별 컴포넌트 분리를 알리는 보조 파일이며 별도의 기하 생성 기능은 없습니다.

## 원근 조작의 불변 조건

잡을 때 저장한 실제 배율을 `referenceScale`, 카메라에서 잡은 지점까지의 거리를 `referenceDistance`라고 하면, 현재 배율은 다음 관계를 유지합니다.

```text
현재 배율 = referenceScale × 현재 배치 거리 / referenceDistance
```

휠 입력으로 크기나 거리를 변경하는 분기는 없습니다. 시선으로 조준한 면과 사물 전체의 공간 여유를 사용해 배치 거리를 계산합니다. 잡은 지점이 화면의 기준점으로 유지되도록 위치와 배율을 함께 계산하므로 피벗 때문에 사물이 위로 밀리는 것을 피합니다.

이동 경로는 먼저 거리를 줄이고 회전한 뒤 새 방향으로 뻗는 순서로 검사합니다. 각 콜라이더의 BoxCast와 최종 Overlap 검사를 통과한 자세만 적용합니다. `Drop`에서는 표시된 최종 자세를 다시 바꾸지 않고 Rigidbody의 중력과 회전 물리를 켭니다.

선택 광선은 플레이어 자신의 CharacterController를 제외하고 가장 가까운 실제 충돌체를 고릅니다. 가까이 놓은 책을 다시 집을 때 자기 몸이 선택을 가리지 않으며, 벽과 다른 사물에 의한 가림은 유지합니다.

## 책과 책꽂이의 관계

조작 가능한 책 40권은 각각 고유 `objectId`, `LibraryProp`, 콜라이더와 Rigidbody를 가집니다. `kind`는 `Book`, `Bookshelf`, `Table`, `Chair`로 구분합니다. 서가 세 곳에 각각 꽂힌 12권, 총 36권도 서가의 하위 물리 사물로 묶지 않으므로 한 권의 이동·배율이 다른 책에 전파되지 않습니다. 책꽂이 5개, 탁자 2개, 의자 2개를 더해 조작 사물은 총 49개입니다.

`ExtractBook`은 책을 잡는 순간 원래 조준 광선을 따라 안전한 범위에서 조금 당깁니다. 1cm 간격으로 기존 충돌 검사를 적용하고 거리·배율 비례 관계를 유지합니다. 같은 칸을 조준하는 동안에는 꺼낸 거리를 유지해 책이 다시 꽂히는 것을 막으며, 시선을 돌리면 일반적인 표면 거리 계산으로 이어집니다.

책이 놓인 가구를 먼저 집으려 하면 위의 책을 옮기라는 안내가 나옵니다. 첫 구역과 마지막 구역의 핵심 서가는 비어 있어 그대로 집을 수 있습니다. `Remember`는 초기 상태를 저장하고, `Restore`는 개별 위치·크기·회전과 초기 정지 상태를 복원합니다.

## 맵과 그림자

`LibraryWorld.Skylights`, `LibraryLighting.Roof`, `ToSun`을 화면과 안전 판정이 함께 사용합니다. 책·가구의 차광 형태는 `LibraryCaster` 배열로 전달되며, 셰이더 전역 이름은 `_Library*`입니다. 미술관의 `_Gallery*` 정보와 분리되어 있습니다.

현재 차광 상한은 128개입니다. 새 사물을 추가해 이 수를 초과하면 씬 준비 단계에서 실패하므로, 새 메시와 콜라이더를 추가할 때 차광 구성도 확인해야 합니다. 사물의 `parts`와 `renderers`를 바꾼 뒤에는 `Remember`를 갱신합니다.

배치와 의도된 풀이의 자세한 설계는 [Layout.md](Layout.md)를 참고합니다. 자동 플레이 결과는 `Validation/Library/Player/library-results.json`에 별도로 저장됩니다.

## 빌드와 공유

```powershell
.\Tools\Build\Build-Library.ps1
.\Tools\Validation\Test-Library.ps1
python Tools/Share/Export-Library-Source.py --output ../03_공유용_소스
```

최종 `Prepare`와 `Build`는 `LibraryAssetImport.Integrate(LibraryGame)`가 실제 원본 에셋을 적용해야 성공합니다. 구조 검증용 `PrepareBlockout`, `BuildBlockout`은 별도 씬·별도 실행 파일을 만들며 최종 실행 바로가기는 이를 사용하지 않습니다. 빌드 메뉴는 씬을 코드로 다시 생성하므로 수동 배치를 보존할 때는 별도 씬으로 저장합니다.

`Parallax_Library_v0.9.0_Source.zip`은 도서관과 기존 미술관이 들어 있는 전체 Unity 프로젝트입니다. `Assets`의 `.meta`, `Packages`, `ProjectSettings`, 필요한 메시·텍스처를 함께 보존하며 캐시·로그·실행 파일은 제외합니다. 파일별 SHA-256은 ZIP 내부 `SourceManifest.json`에 기록합니다. 내보내기 도구는 원본 통합 기록과 최종 에셋 빌드 성공 기록이 있어야 ZIP을 생성합니다.
