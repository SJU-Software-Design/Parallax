# 미술관 코드 길잡이

현재 씬: `Assets/Parallax/Gallery/Scenes/Gallery.unity`

## 핵심 소스

| 파일 | 담당 동작 |
| --- | --- |
| `Gallery/Scripts/GalleryGame.cs` | 플레이어 이동, 조준, 잡기·놓기, 표면 거리 계산, 원근 배율, 배치 중 충돌 검사, 노출·복귀·진행 |
| `Gallery/Scripts/GalleryProp.cs` | 전시물 초기 상태, 잡는 동안과 놓은 뒤의 Rigidbody 상태, 질량, 강조 표시 |
| `Gallery/Scripts/GalleryWorld.cs` | 전시실·복도·발판·출구와 퍼즐 사물 구성 |
| `Gallery/Scripts/GalleryGeometry.cs` | 메시·기하 보조 처리 |
| `Gallery/Scripts/GalleryLighting.cs` | 채광 구역과 그림자 안전 판정, 셰이더에 차광 사물 정보 전달 |
| `Gallery/Scripts/GalleryCaster.cs` | 그림자를 만드는 사물의 형태·변환 정보 |
| `Gallery/Resources/GallerySurface.shader` | 빛과 그림자 화면 표현 |
| `Gallery/Scripts/GalleryHud.cs`, `GalleryLabel.cs` | 메뉴·상태·힌트와 공간 안내문 |
| `Gallery/Editor/GalleryBuild.cs` | 원본 전시물 에셋 연결, 씬 생성, Windows 빌드 |
| `Gallery/Validation/GalleryPerspectiveValidation.cs` | 가까이/멀리 배치, 배율 유지, 낙하, 충돌과 그림자 자동 검증 |

위 표의 경로는 `Assets/Parallax/` 기준입니다.

## 처음 읽는 순서

1. `GalleryGame.Update`에서 입력 처리와 조작 흐름을 확인합니다.
2. `Interact`에서 잡는 기준점과 초기 거리·크기를 확인합니다.
3. `ResolvePlacementDepth`, `PerspectivePose`, `UpdateHeldPose`에서 시선 거리와 원근 배율, 이동 중 충돌 처리를 확인합니다.
4. `GalleryProp.BeginHold`와 `Release`에서 조작과 물리가 전환되는 지점을 확인합니다.
5. `GalleryLighting`과 `GallerySurface.shader`에서 같은 차광 정보를 판정과 화면에 사용하는 방식을 확인합니다.

## 공통 코드와 이전 실험

`Shared/Scripts/ShadeRules.cs`에는 Player 등의 공통 자료형과 기존 규칙이, `IndoorRules.cs`에는 미술관 시선 계산에서도 사용하는 보조 함수가 있습니다. 기존 기능을 바꾸지 않기 위해 네임스페이스와 클래스명은 유지했습니다.

`Legacy/Scripts`는 `Courtyard`, `KeyPuzzle`, `ShadowPuzzle`, `Indoor`로 나누었습니다. 이전 씬은 `Legacy/Scenes`, 이전 빌드·규칙 검증 코드는 `Legacy/Editor`에 있습니다. 이전 버전의 F 조작 설명은 현재 미술관에 적용되지 않습니다.

`Gallery/Generated`와 `ThirdParty/ALLrounder18`의 메시·텍스처, `.meta` 파일은 저장된 씬의 참조 대상입니다. C# 파일만 복사하면 같은 미술관을 실행할 수 없으므로 전체 소스 ZIP을 공유하세요.
