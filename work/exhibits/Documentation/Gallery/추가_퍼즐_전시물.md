# 미술관 퍼즐 전시물 추가판

2026-10-03. 기존 9개 조작 사물에 새 3D 전시물 2개를 더했습니다.

| 전시물 | 초기 위치 | 사용 |
| --- | --- | --- |
| 청화 각병 | 1구역 입구 오른쪽, (3.25, 0.95, 5.35) | 넓은 몸체로 햇빛 가리기, 평평한 뚜껑을 발판으로 쓰기 |
| 겹창 조각 | 2구역 왼쪽, (-4.3, 1.40, 17.1) | 회전해 서로 다른 창틀 그림자를 겹치기, 눕힌 프레임 활용 |

두 전시물 모두 청록색 표식이 있습니다. 기존 왼쪽 클릭 잡기/놓기, 시선 거리에 따른 확대/축소, Q/E 및 Z/X 회전, 오른쪽 클릭 취소, R 구역 초기화를 그대로 사용합니다. 새로운 퍼즐 정답 조건이나 클리어 조건은 추가하지 않았습니다. 기존 구역에서 활용할 수 있는 추가 도구입니다.

## 소스 연결

- `Assets/Parallax/Gallery/Scripts/GalleryPuzzleExhibits.cs`: 두 전시물의 입체 형태, 재질, 초기 위치, 바닥 설명. 실제 큐브 메시와 동일한 박스 충돌체/그림자 차폐체로 구성했습니다.
- `GalleryGame.Awake`: 기존 씬으로 Play해도 전시물 추가. 중복 생성 방지.
- `GalleryBuild.Prepare`: 씬 재생성 시에도 추가하고 재질을 저장합니다. 에디터에서 열자마자 씬에 저장하려면 기존 **Parallax → 미술관 씬 준비** 메뉴를 사용합니다. 이 메뉴는 기존 설계대로 씬 전체를 재생성하므로 수동 씬 변경은 먼저 별도 보관하세요.
- `Assets/StreamingAssets/GalleryExhibits/cobalt-porcelain.png`: 직접 생성한 청화 식물 문양 원본 이미지.
- `Assets/Parallax/Gallery/Validation/GalleryExhibitValidation.cs`: `-gallery-exhibits-test`로 실행하는 추가 사물 검증.

## Windows 추가판

Unity Editor 설치가 확인되지 않아 기존 6000.3.24f1 Windows 플레이어의 별도 복사본에서 전체 런타임 C# 소스를 컴파일했습니다. 기존 실행 파일 폴더는 수정하지 않았습니다. 추가판은 `Parallax_Unity_v0.8.2_Exhibits/Parallax.exe`입니다. Unity Editor를 통한 전체 재빌드 및 에디터 메뉴 실행은 이 환경에서 검증하지 않았습니다.

기존 플레이어는 미사용 API가 제거되어 있으므로 `PARALLAX_EXISTING_PLAYER` 조건에서는 같은 PNG를 손실 없는 RGBA 바이트로 변환해 이미 포함된 API로 읽습니다. 일반 Unity 프로젝트 빌드에서는 원본 PNG를 읽습니다. 컴파일 시 제거된 상수는 임시 복사본에서 동일한 리터럴로 치환하며 원본 코드의 계산식은 유지합니다.

검증 범위는 실제 카메라 조준으로 잡기/크기 변경/회전, 공중에서 놓기와 PhysX 낙하, 관통 검사, 그림자-충돌체 일치, 취소 및 구역 초기화입니다. 검증마다 플레이어만 대상 앞의 안전한 위치에 놓습니다. 사물 위치·크기를 시험용 값으로 직접 지정하지 않습니다. 전체 4구역 수동 완주 결과는 아닙니다.

## 제작 기록

입체 형태는 프로젝트 코드로 직접 제작했으며 기존 외부 그림 에셋의 이미지를 생성 입력으로 사용하지 않았습니다. 청화 문양은 내장 image_gen으로 새로 생성했습니다. 원본 파일명: `cobalt-porcelain.png`.

생성 프롬프트:

Primary request: an original cobalt-blue hand-painted botanical and flowing-cloud ceramic design on warm ivory porcelain, for a square-bodied lidded exhibition vessel. The entire image is the flat unwrapped material surface, edge-to-edge, orthographic, no perspective, no actual vase or object. Elegant restrained blue ink brushwork, a central flowing botanical motif with thin stems, stylized leaves and two small cloud spirals, ample warm ivory negative space, subtle fine glaze speckling. Sophisticated museum collectible, clean readable shapes at game resolution. Palette: warm off-white 75 percent, indigo and muted cobalt 25 percent. Delicate narrow blue border approximately 4 percent inside all edges, balanced composition. Uniform diffuse albedo only, no shadows, no lighting gradients, no highlights, no metallic reflections, no text, no logos, no watermark, no scene, no 3D render. Square image, opaque background.
